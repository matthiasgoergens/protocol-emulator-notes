Mappings and sources of the need:
- 1-bit correlation (GPS tracking, binary NN): S <- S + (g ? -A : A), g = broadcast lane (designed, gps). Need: 12 ch x 6 corr x 3.27 MS/s (gps-hotcold README).
- multi-bit x +-1 code (DSSS, soft matcher): same configuration, multi-bit A. Need: no application found beyond GPS.
- HF direct-sampling DDC (8-bit ADC, I/Q, CIC3): 32-bit NCO (2), square-LO mixers (2), 3 x 32-bit integrators per arm (12); est; needs an 8x8 mixer for image rejection. Need: 0-30 MHz needs >= 60 MS/s (Nyquist).
- edit distance (Myers on host): about 4 PE-ops per DP cell, est; needs two links (see DTW). Need: none found at a rate the host misses.
- Viterbi K=7 r=1/2 (CCSDS): no direct mapping: one link and a static op give 2 words per ACS through a bank, two passes per bit, per-word control bits and a half-word label write; est about 10 PEs and 5.3 clocks per butterfly per chain, at most one chain per bank (2). Need: CCSDS K=7 at 1 Mbit/s (upper end of cubesat downlinks, est); 250 bit/s for Galileo E1-B / SBAS is 8,000/s.
- dynamic time warping: does not map on upe_v0 (one link, static op); est 5 PE-clocks with a second link. Need: offline trace matching: latency, not a rate.
- min-plus relaxation (shortest paths): P <- A + K, then S <- min(S, A): 2 PEs per relaxation (designed). Need: Floyd-Warshall n = 64 at 50 frames/s, est.
- wavetable voice at 48 kHz: the array makes 60 MHz square/noise voices, not 48 kHz samples (synth.ml). Need: 16 voices at 48 kHz.
- 1-D cellular automaton, 256 cells per line: 16 cells per word, about 6 GF(2) ops per word, est. Need: 256 cells x 15,625 lines/s.
- Mandelbrot: no multiplier: 3 shift-add multiplies of 16 steps, est. Need: 256 x 192 x 50 frames x 20 iterations.
- Reed-Solomon syndromes: GF(256) constant multiply as 8 gated XORs, one K per PE, est. Need: no reachable link above 7 Mbit/s.
- CRC polynomial search, brute force: CRC mode, one candidate per PE (designed). Need: a one-off; the GCD method (CRC RevEng) needs no search.
- raycaster (column DDA): data-dependent loop with a map lookup: no fit. Need: 256 rays x 20 steps x 50 frames.
- LZ77 longest match: a window of 32 bytes in 16 PEs: too small to matter, est. Need: host hash chains visit few positions.
- PDM microphone decimation (CIC3): CIC integrators, one PE per stage (designed). Need: one microphone at 3.072 MHz.
- streaming top-16 / insertion sort: S <- max(S, A), P <- loser (designed). Need: one 60 MS/s stream; on ordinary data the host tests each sample against the 16th largest first (est 2-3 cycles, 40-60 % of both cores) and inserts rarely; rising data needs 16 steps per sample (960M/s).
